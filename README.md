# 🌍 MiniCraft Mundo Animal - Maria Luiza 4A

Jogo estilo Minecraft 2D com **todos os animais do mundo** e **modo criativo**!

## 🎮 Jogar
- Online (GitHub Pages): ative o Pages e acesse o link
- Local: abra `index.html` no navegador

## ✨ Recursos
- Mundo procedural 128x128 com biomas (grama, floresta, deserto, neve, praia, oceano)
- 45+ animais: vaca, porco, galinha, ovelha, lobo, leão, tigre, elefante, girafa, panda, pinguim, tubarão, baleia, crocodilo, cobra e muito mais!
- Modo Sobrevivência + Modo Criativo (tecla C)
- Criativo: voar, vida infinita, todos os blocos infinitos, ovos de spawn
- Enciclopédia de animais descobertos
- Dia/noite, salvar/carregar, chuva de animais

## 🕹️ Controles
WASD/setas mover | clique quebrar | botão direito colocar | 1-9 hotbar | C criativo | E inventário | Espaço voar
